# 短码绑定库（g########）

每个 `g` + 8 位数字对应一份 JSON：

```json
{
  "v": 1,
  "code": "g48291037",
  "box": "<支援卡 base64>",
  "cidol": "<角色绑定 base64>",
  "box_count": 118,
  "cidol_count": 20
}
```

- 网页：本站「生成并上传短码」写入这里
- Bot：`/绑定 g48291037` 通过
  `https://raw.githubusercontent.com/kitsurato/mini-gkms-box/main/binds/g48291037.json`
  查询（跨机器互通，不依赖本机文件）
